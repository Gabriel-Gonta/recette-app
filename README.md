# Sèche — Salle & Repas

Webapp perso (PWA) : programme de salle du jour + plan repas salé à la japonaise, liste de courses et suivi du poids.

- **Modifier le plan** : tout est dans `data.js` (séances, recettes en grammes, menu de la semaine). Les macros sont calculées automatiquement.
- **Installer sur iPhone** : ouvrir le lien dans Safari → Partager → « Sur l'écran d'accueil ».
- Les données perso (séries cochées, charges, poids) restent sur le téléphone (stockage local).
